# ED825 IRB Readiness Center

Student-facing supplemental resource for **ED825: Applied Research and IRB Preparation**.

## Recommended GitHub repository name

`ED825-IRB-Readiness-Center`

## Recommended Render service name

`ed825-irb-readiness-center`

## Purpose

The site supports students as they coordinate paper revision with IRB packet preparation. It includes:

- ED825 parallel progression model (without an extension/repeat decision point)
- Current-status guidance
- Proposed pathway materials guide
- Mock IRB packet inventory
- Site permission alignment check
- Cross-document alignment matrix
- Recruitment and participant-facing materials checks
- Privacy/confidentiality/data-security checks
- Platform-settings verification
- Participant-time calculator
- Pre-submission scan
- Official submission steps
- Post-approval reminders
- Printable readiness summary
- Browser-local progress storage

## Important boundaries

This site does **not**:

- make an official IRB pathway determination;
- grant IRB approval;
- authorize recruitment, consent, access to research records, or data collection;
- write or rewrite protocol responses, consent language, recruitment language, or research instruments;
- replace the current Brightspace assignment, rubric, EdD Student Handbook, PG IRB Investigator Guide, official forms/templates, or faculty/RPC/IRB guidance.

## GitHub upload

Upload the **contents of this folder**, not the ZIP file itself. Keep `index.html`, `app.js`, `styles.css`, `render.yaml`, `README.md`, `purdue-global-logo.png`, and the `resources/` folder at the repository root.

## Render

Create a new Render Blueprint connected to the GitHub repository. Render will read `render.yaml` and publish the static site.

## Privacy

Checklist progress, status selections, pathway selection, alignment checks, and participant-time entries are stored using browser `localStorage`. No information is sent to a server by this site. Clearing browser/site data, using private/incognito mode, or changing browsers/devices may erase saved progress.

## Resource-publication note

Internal faculty/RPC build materials and the individual student site-permission example used during development are **not** included in the public resource folder.
